# 權利 vs 權力｜3分鐘極限挑戰

國中公民限時答題競賽。學生輸入學號登入，3 分鐘內判斷每一題是「權利」還是「權力」，伺服器即時計分，保留每人最高分並顯示 Top 10 排行榜；教師後台可查看成績、題目答對率，並匯出 CSV。

- **技術**：Node.js（22.13 以上）＋內建 SQLite，**不需要安裝任何套件、不需要另外架資料庫**。
- **資料**：全部存在 `data/game.db` 一個檔案裡，備份就是複製這個檔案。
- **防作弊**：答案只存在伺服器，學生的瀏覽器拿不到；作答時間、分數、冷卻都由伺服器計算。

---

## 一、5 分鐘快速開始（在自己的電腦試玩）

1. 安裝 Node.js：到 <https://nodejs.org> 下載 **LTS 版**（22.13 以上）並安裝。
2. 解壓縮本專案，在資料夾中開啟「終端機／命令提示字元」。
3. 設定後台密碼：把 `.env.example` 複製一份改名為 `.env`，修改 `ADMIN_PASSWORD=` 後面的密碼（至少 8 個字元）。
4. 載入範例資料（12 位示範學生、200 題完整題庫）：

   ```bash
   npm run demo
   ```

5. 啟動：

   ```bash
   npm start
   ```

6. 打開瀏覽器：
   - 學生遊戲：<http://localhost:3000>（示範學號 `70101`～`70106`、`70201`～`70206`）
   - 教師後台：<http://localhost:3000/admin>

> 啟動時畫面會列出「區域網路」網址（例如 `http://192.168.1.23:3000`），同一個 Wi-Fi 下的學生用手機或平板輸入這個網址就能玩。

## 二、匯入學生名單

準備一份 CSV（第一列是欄位名稱）：

| 學號 | 姓名 | 班級 | 座號 |
|---|---|---|---|
| 70101 | 王小明 | 701 | 1 |
| 70102 | 李小華 | 701 | 2 |

- 必填：**學號、姓名、班級**；座號可省略。
- 學號一律當文字處理，`00123` 開頭的 0 不會不見。
- 學號已經存在時，會更新姓名與班級，**成績不受影響**。
- 勾選「停用不在這份名單裡的學生」：適合新學年換名單；被停用的學生不能登入、不會出現在排行榜，但成績保留。

**匯入方式（二選一）**

- 教師後台 →「匯入名單／題庫」→ 選擇檔案 → 匯入名單（建議）
- 指令：`npm run import:students -- 名單.csv`（加上 `--deactivate-missing` 可停用名單外的學生）

## 三、題庫格式（200 題）

| 題號 | 題目 | 答案 | 難度 | 類別 | 解析 |
|---|---|---|---|---|---|
| Q001 | 立法院制定法律，是在行使國家的立法＿＿。 | 權力 | 1 | 定義辨識 | 制定法律是國家機關行使立法權力。 |
| Q053 | 警察小李下班後，到投票所投下自己的一票，這是在行使＿＿。 | 權利 | 3 | 概念判斷 | 小李以一般國民身分投票，行使的是參政權利。 |

| 欄位 | 必填 | 說明 |
|---|---|---|
| 題號 | 建議 | 每題唯一的代號（如 Q001）。**系統用題號辨認同一題**，之後修改題目內容再匯入，作答統計會延續。 |
| 題目 | ✔ | 200 字以內。 |
| 答案 | ✔ | 只能填「權利」或「權力」。 |
| 難度 | 建議 | 1＝基本辨識、2＝生活情境、3＝概念判斷（也可填「易／中／難」）。沒填視為 2。 |
| 類別 | | 自由填寫，方便後台檢視。 |
| 解析 | | 學生答錯時，結算畫面的「錯題回顧」會顯示。**強烈建議填寫**，學習效果最好。 |

**修改題庫的流程**：後台「匯入名單／題庫」→「下載目前題庫」→ 用 Excel 修改 → 另存 CSV → 再匯入。

- 預設勾選「停用不在這份檔案裡的題目」：匯入的檔案就是完整題庫。停用的題目不再出題，但作答紀錄保留。
- 檔案中只要有一列錯誤（答案打錯字、題號重複…），**整份都不會匯入**，畫面會列出第幾列有什麼問題。
- Excel 存檔請選「**CSV UTF-8（逗號分隔）**」；一般的 CSV（Big5）也讀得懂。
- 指令方式：`npm run import:questions -- 題庫.csv`（加上 `--keep-missing` 則不停用檔案外的題目）。

### 出題時避免被「規律」猜中

匯入時系統會自動檢查並提醒：

- 權利／權力的題數是否大約各半。
- 各難度的題數是否足夠維持出題比例。
- 題目出現「政府、警察、法院…」時答案是否幾乎都是「權力」；出現「人民、學生、民眾…」時是否幾乎都是「權利」。
- 「依法」兩個字是否集中在某一種答案（很常見的洩題方式）。

建議至少 1/4 的題目是「**身分相同、答案不同**」的反例，例如：

| 題目 | 答案 | 為什麼 |
|---|---|---|
| 警察在路口依法攔檢可疑車輛 | 權力 | 執行公務 |
| 警察下班後到投票所投票 | 權利 | 以國民身分 |
| 縣政府依法對違規工廠開罰 | 權力 | 執行公務 |
| 工廠被開罰後依法提出訴願 | 權利 | 主張救濟 |
| 市長下班到餐廳消費，向店家要求退費 | 權利 | 以消費者身分 |

另外避免答案有爭議的題目，例如「議員質詢」「公務員依法請假」這類，學生可能從不同角度都說得通；若要保留，請在解析清楚寫出判斷依據。

> `samples/questions.csv` 是已整理好的 200 題完整題庫（權利、權力各 100 題，難度 80／80／40），可直接匯入使用，或下載後修改再匯入。原稿在 `scripts/bank-source.py`。

## 四、調整遊戲規則

所有數值集中在 **`config.js`**，每一項都有中文註解。修改後重新啟動伺服器即可（進行中的對局沿用開局時的設定）。

| 想調整 | 修改 |
|---|---|
| 遊戲時間 | `game.durationSeconds`（秒） |
| 答對基本分、答錯扣分 | `scoring.correctBase`、`scoring.wrongPenalty` |
| 速度獎勵 | `scoring.speedBonus`（`max`＝最高加分、`lossPerSecond`＝每秒遞減） |
| Combo 獎勵 | `scoring.combo.milestones`（例如 `{ 3: 10, 5: 20, 10: 50 }`）、`scoring.combo.repeat` |
| 連錯冷卻 | `cooldown.triggerAtConsecutiveWrong`（幾題）、`cooldown.seconds`（暫停秒數） |
| 難度比例 | `selection.difficultyMix`（預設每 10 題 4 題易、4 題中、2 題難） |
| 按鈕固定或隨機 | `selection.shuffleButtons`（`false`＝固定、`true`＝每題隨機） |
| 成績單等第門檻與評語 | `grades` |
| 成績單標題 | `reportCardTitle` |
| 排行榜名次 | `leaderboard.size` |
| 分數可否為負 | `scoring.minScore`（預設 0；改成 `null` 允許負分） |

設定若打錯（例如把數字寫成文字），伺服器啟動時會直接指出哪一項有問題。

### 已實作的規則細節

- 速度獎勵 `max(0, 50 − 10 × 作答秒數)`，四捨五入成整數；作答秒數由伺服器從「題目出現」算到「收到答案」。
- Combo：連對第 3、5、10 題各加 10、20、50；之後第 15、20、25… 題各加 30。
- 連錯 2 題起，每次答錯都暫停 2 秒（倒數照走）；答對後連錯歸零，答錯後 Combo 歸零。
- 開始前有 3-2-1 倒數，不計入 3 分鐘。
- 出題：每 10 題一輪，固定 4:4:2 的難度比例、權利／權力各 5 題，同一答案最多連續 3 題；200 題出完前不重複。
- 按鈕位置：固定左「權利」、右「權力」（鍵盤 ← ＝權利、→ ＝權力）。想改回每題隨機交換，把 `config.js` 的 `selection.shuffleButtons` 改成 `true`。
- 排行榜：每位學生只取最高分；同分時先達到的排前面；只顯示名次、姓名、班級、分數。
- 第一局不顯示 NEW RECORD；之後超過歷史最高分才顯示。
- 中途重新整理頁面會接續同一局（時間照算）；重新按「開始挑戰」會結束上一局。

### 成績單等第

結算畫面以成績單呈現，並依「本次分數」與「正確率」給等第。**兩個條件都達到**才給該等第：

| 等第 | 分數 | 正確率 | 大約是哪種學生（模擬結果） |
|---|---|---|---|
| 優 | ≥ 5,000 | ≥ 80% | 每題約 3 秒、答對 85% 以上 |
| 甲 | ≥ 3,500 | ≥ 75% | 每題約 3.5 秒、答對約 80% |
| 乙 | ≥ 2,000 | ≥ 70% | 每題約 4 秒、答對約 70% |
| 丙 | ≥ 1,000 | ≥ 60% | 每題約 4 秒、答對約 60～65% |
| 丁 | 1,000 以下，或正確率未達 60% | | |

設正確率門檻的原因：模擬發現，學生如果不看題目、每題 0.7 秒亂按，中位數約可拿 6,200 分，比認真作答、答對 85% 的學生（約 5,500 分）還高。有了正確率門檻，亂猜的人等第只會是「丁」。成績單也會提示「下一個等第還差什麼」。

> 若也不希望亂猜的人登上排行榜，建議把 `scoring.wrongPenalty` 從 50 改成 100：模擬中亂猜的中位數會降到約 3,000 分，低於答對 80% 的學生，而認真作答的學生分數只少約 5%。

## 五、教師後台

網址 `/admin`，以 `.env` 的 `ADMIN_PASSWORD` 登入（登入 8 小時有效；連續輸錯 10 次會鎖 15 分鐘）。

- **學生成績**：最高分、最佳等第、遊玩次數、總正確率、平均作答秒數、最近遊玩；點學生可看每一局。可搜尋、排序、只看玩過的人。
- **題目統計**：每題作答次數、答對率、平均秒數；可只看答對率低於 60% 的題目。
- **班級篩選**：右上角選班級，所有統計與匯出都會跟著篩選。
- **匯出 CSV**：學生成績總表、每局成績、作答明細、題目統計、學生名單、題庫（Excel 可直接開啟）。

## 六、部署

### A. 學校電腦／教室筆電（最簡單，適合單一節課）

照「快速開始」做，學生和老師的電腦連同一個網路即可。注意：

- Windows 第一次啟動時若跳出防火牆詢問，請選「允許」。
- 學校網路若擋住裝置互連，可請資訊組開放 3000 埠，或改用下面的雲端方式。

### B. 雲端平台（Zeabur、Railway、Render 等）

1. 把專案放到 GitHub（`.env` 與 `data/` 已在 `.gitignore`，不會上傳）。
2. 在平台建立 Node.js 服務，連結 GitHub 專案；啟動指令 `npm start`。
3. **掛載永久儲存空間（Volume）**，例如掛在 `/data`。
   ⚠ 沒有永久儲存空間，每次重新部署都會清空成績！
4. 設定環境變數：

   | 變數 | 值 |
   |---|---|
   | `ADMIN_PASSWORD` | 後台密碼 |
   | `DATA_DIR` | `/data`（剛剛掛載的位置） |
   | `TRUST_PROXY` | `1` |
   | `COOKIE_SECURE` | `1` |

5. 部署完成後，到 `/admin` 登入並匯入名單與題庫。

> 本程式使用單一 SQLite 檔案，請只開 **1 個執行個體**（不要開自動擴展）。一個伺服器同時服務全年級數百人沒有問題。

### C. 自己的 Linux 主機

```bash
# 安裝 Node.js 22 LTS 後
cd rights-power-game
cp .env.example .env && nano .env        # 設定密碼
npm run import:students -- 名單.csv
npm run import:questions -- 題庫.csv
npm start
```

長期執行可用 systemd 或 `pm2 start server.js --name rights-power`；前面放 Nginx 加上 HTTPS 時，記得在 `.env` 設 `TRUST_PROXY=1`、`COOKIE_SECURE=1`。

## 七、備份與還原

```bash
npm run backup      # 產生 data/backups/game-日期時間.db（執行中也可以備份）
```

還原：停止伺服器 → 把備份檔複製成 `data/game.db` → 重新啟動。
新學期想全部重來：停止伺服器，刪除 `data/game.db`（請先備份），重新匯入名單與題庫。

## 八、檔案結構

```
config.js              ← 遊戲規則設定（時間、計分、Combo、冷卻、難度比例）
schema.sql             ← 資料庫結構
server.js              ← 啟動入口
lib/
  game.js              ← 開局、出題、判分、結算、排行榜
  scoring.js           ← 計分公式
  sequence.js          ← 出題順序與按鈕位置
  importers.js         ← 名單與題庫匯入、題庫檢查
  admin.js             ← 後台統計與 CSV 匯出
  admin-auth.js        ← 後台密碼驗證
  app.js / http.js     ← API 路由、安全標頭
public/
  index.html, js/game.js, css/style.css     ← 學生遊戲畫面
  admin.html, js/admin.js, css/admin.css    ← 教師後台
samples/               ← 範例名單與題庫
scripts/               ← 匯入、備份指令
test/                  ← 自動測試（npm test）
data/                  ← 資料庫（自動建立）
```

### 資料表

| 資料表 | 內容 |
|---|---|
| `students` | 學號、姓名、班級、座號、是否啟用 |
| `questions` | 題號、題目、答案、難度、類別、解析、是否啟用 |
| `game_sessions` | 每一局：學生、開始／結束時間、分數、答對數、最高 Combo、是否破紀錄、開局時的設定 |
| `answers` | 每一題作答：題目、學生選擇、對錯、作答毫秒數、按鈕排列、得分明細 |
| `v_best_sessions`（檢視表） | 每位學生分數最高的一局，排行榜與後台使用 |

## 九、注意事項

- **學號就是登入憑證**：知道同學學號的人可以用他的名義玩。由於只保留最高分，冒名者無法拉低別人成績，但可能幫別人刷高分。若有疑慮，後台的「每局成績」與「作答明細」可看出每局的時間點；也可以在名單中改用不易猜測的代碼（如學號＋兩碼隨機數）讓學生登入。
- 本程式使用 Node.js 內建的 SQLite（`node:sqlite`），官方仍標示為實驗性功能，但已相當穩定；啟動時的相關警告已隱藏。
- 執行 `npm test` 可跑完整的自動測試（計分、出題、匯入、API 流程）。
